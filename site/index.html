What it actually does

Clickboard doesn't watch your clipboard in the background and it doesn't touch the cloud. Click a machine in the tray menu and it opens an SSH connection to it; while that's open, whatever you copy on either end shows up on the other. Click it again and it stops — nothing runs, nothing's listening, no surprise overwrite of a clipboard you didn't mean to share.

Setup takes two steps

Point it at a machine's hostname and user, then either run ssh-copy-id yourself or use the built-in pairing flow — generate a short code on both machines, and Clickboard exchanges SSH keys for you, with a fingerprint you confirm by eye before anything's trusted.

No auto-sync Every transfer starts with a click. Disconnect and it's off.
Plain SSH No account, no relay server holding your clipboard.
Open source Read the code, self-host the pairing broker, or both.

Install

Ubuntu 24.04, tested. Sets up a virtual environment and a tray launcher — asks for sudo only for the two system packages it can't install any other way, and tells you before it does.

cd ~/Downloads && mkdir -p clickboard && tar xzf clickboard-latest.tar.gz -C clickboard && bash clickboard/install.sh
