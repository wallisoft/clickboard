Features

Finds your machines

Machines signed in with the same key discover each other on your local network automatically.

Yours alone

Other people on the same Wi-Fi can't join. Every new machine is announced, with a one-click Remove.

Encrypted end to end

Clipboard contents travel directly between your machines over encrypted connections. They never touch our servers.

Lives in your tray

A small icon shows what's connected. Pause a machine with one click.

Linux and Windows

Any mix of Linux and Windows 10 and 11 machines on the same network.

Images, files and folders

Screenshot on one machine, paste into an editor on another. Copy a folder in one file manager, paste it in the other.

Install

One command. It installs everything Clickboard needs, and starts it when you log in. Run it again any time to update.

Linux (Ubuntu 24.04 and similar, in a terminal)

curl -fsSL https://raw.githubusercontent.com/wallisoft/clickboard/main/install.sh | bash

Asks for your password once, to add the clipboard and tray tools it needs and open its ports if your firewall is on.

Windows 10 and 11

Download for Windows

Run Clickboard-Setup.exe and follow the steps. Until our Microsoft Store listing arrives, Windows may say "Windows protected your PC": click More info, then Run anyway.

Prefer the command line? In PowerShell:

irm https://raw.githubusercontent.com/wallisoft/clickboard/main/install.ps1 | iex

Prefer to read before you run? Both installers are on GitHub.

Your key is used only to confirm which machines belong to you. We store each machine's name, its network address and its public key, and nothing you copy.
